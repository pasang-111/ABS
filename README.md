# After Built Solutions — Redesign

Modern redesign of the official ABS brand site.

## Theme
- **Grey** base (`#0c0f14` → `#222b38`)
- **Orange** accents (`#f97316`)
- Original brand assets retained (logos, “Did you know” graphic)

## What’s new
- Advanced CSS Grid / bento layouts
- Navbar with **mega menu + images**
- Cinematic hero with auto-rotating slides + bento visual
- Interactive **Before & After** drag slider
- Brochures section
- Full **contact form** (client-side validation + loading state)
- Smooth reveal animations, hover transitions, floating elements
- Fully responsive & performance-focused

## Run

```bash
cd abs-redesign
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
